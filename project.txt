Java + Spring REST API — AI-Driven Development Exercise
Objective
Develop a RESTful API using Java + Spring Framework to manage Clients and
their associated Documents, implementing full CRUD operations.
This exercise should be completed using an AI-driven development approach.
You are encouraged to use AI coding agents throughout the development lifecycle,
preferably using:
OpenCode → Ollama → Qwen
The goal is not simply to generate code with AI, but to use AI agents as part of the
software engineering process: planning, implementation, testing, debugging, code
review, and iterative improvement.
Requirements
1. Java + Spring API
Create a Java + Spring REST API supporting full CRUD operations:
 
 
 
 
POST — Create a Client
GET — Retrieve Client(s)
PUT — Update a Client
DELETE — Delete a Client
Follow REST conventions when designing endpoints, HTTP status codes, and
request/response payloads.
2. Client Entity
The Client entity must contain at least:
 
 
 
 
 
 
 
Id
FirstName
LastName
TaxIdentifier
Email
PhoneNumber
Documents — one-to-many relationship
3. Document Entity
The Document entity must contain at least: 
 
 
 
Id
Number
Description
ExpirationDate
A Client may have multiple Documents.
4. Database
Use an H2 in-memory database. Another database may be used if preferred.
The implementation must:
 
 
 
Persist Clients and their Documents within a single transaction,
guaranteeing atomicity.
Automatically create/manage the required database schema, or provide
the necessary database migration/schema scripts.
You may use mechanisms such as JPA/Hibernate schema generation,
Liquibase, or equivalent configuration.
5. Build Tool
Use either:
 
 
Maven, or
Gradle
The project should be buildable and executable using the selected build tool.
6. Testing
Implement automated tests covering at least the happy path of every API
endpoint.
Tests should be executable through the selected build tool.
Additional tests covering validation, error handling, transactional behavior, or edge
cases are encouraged.
7. APIs
At minimum, implement:
 
 
 
 
 
POST /clients
GET /clients
GET /clients/{id}
PUT /clients/{id}
DELETE /clients/{id}Also create a Login API that can be used for authentication if JWT support is
implemented.
The exact URI structure may differ if there is a clear and consistent REST API
design.
AI-Driven Development
You are expected to use AI-assisted/agentic development as part of this
exercise.
The preferred setup is:
OpenCode → Ollama → Qwen
Other AI-assisted development tools may be used, but preference should be given
to a local agentic workflow where the AI agent can inspect the project, modify
files, run builds/tests, analyze failures, and iteratively improve the
implementation.
Suggested Agent Workflow
Use the AI agent iteratively rather than asking it to generate the entire project in a
single prompt.
A suggested workflow is:
1. Ask the agent to analyze the requirements.
2. Ask it to propose an implementation plan and architecture before writing
code.
3. Break the implementation into small, verifiable tasks.
4. Let the agent implement tasks incrementally.
5. Ask the agent to build and run the project.
6. Ask it to create and execute the required automated tests.
7. Let the agent investigate and fix compilation or test failures.
8. Ask the agent to perform a code review of its own implementation.
9. Review the proposed changes yourself and challenge questionable
decisions.
10. Iterate until the requirements are satisfied and all tests pass.
AI-generated code should not be accepted blindly. You remain responsible for
understanding, validating, and explaining the submitted solution.
